PROJECT OVERVIEW

About CropYield AI

An academic machine-learning prototype for crop yield estimation and model explainability.

✳
PROJECT GOAL

Make model predictions easier to understand.

This application uses separate ExtraTrees regression pipelines for Onion and Sugarcane. SHAP provides local feature contributions to help inspect why a prediction differs from the model's baseline.
